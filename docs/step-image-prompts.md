# Step photos – prompts

Each service step shows a photo of the team at work. The project ships with crops of the existing
`public/cycle/*.webp` photos. To replace one, generate an image with the prompt below (4:3, ~1200×900),
save it as WebP and overwrite the file named next to it. No code change is needed.

**Style line to add to every prompt:** Photorealistic professional photo, modern digital agency office, transparent glowing holographic glass tiles with simple icons floating above the laptop screen, cinematic lighting, shallow depth of field, 4:3. No readable text, no logos, no watermarks.
